# Myra for Squads — prototype

A static, single-page mobile prototype. No build step and no dependencies to install.

## Files
- `index.html`: the whole prototype (HTML, CSS and JS in one file)

## Deploy on Vercel
1. Put this folder in a new project, or drag it into vercel.com/new.
2. Framework preset: **Other**. Leave the build command and output directory empty.
3. Deploy. The site root opens the prototype.

To deploy from the command line instead, run `npx vercel` inside this folder and accept the defaults.

## Notes
- Photos load from Unsplash, icons from jsDelivr (Tabler icons 3.19.0) and fonts from Google Fonts, so the page needs an internet connection.
- It is best viewed at phone width, or on desktop where it shows inside a phone frame.
